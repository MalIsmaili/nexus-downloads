(02) Install

Four steps on each device. That’s it.

Windows .exe

  1. Download the installerUse the Download for Windows button and wait for it to finish.
  2. Open NEXUS-Agent-SetupDouble-click it in your Downloads folder.
  3. If Windows protects your PCClick More info → Run anyway.
  4. Finish the setupFollow the installer, then open NEXUS from the Start menu.

Why the warning?NEXUS comes straight from this page, not a store, so Windows doesn’t recognise it yet.

Android .apk

  1. Download the fileOn your phone, use the Download for Android button.
  2. Open the downloaded fileTap it in your notifications or Downloads.
  3. Allow unknown appsWhen Android asks, switch on Allow unknown apps for your browser or file manager.
  4. Tap Install, then open NEXUSChoose Create account and type this in Server: https://malnexus.duckdns.org

Why the permission?Android asks this for any app installed from outside an app store. You can switch it off again afterwards.
